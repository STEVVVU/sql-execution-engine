# Feature map

- library.md describes upstream Arrow operators and public consumer tests.
- sql.md describes SQL execution, table loading, exact joins, and grouped aggregation.
- The benchmark path runs `python3 scripts/benchmark.py --output evidence/benchmark` after a locked release build. It sweeps 1,000, 100,000 and 1,000,000 disk CSV rows with aggregate, selective filter, grouped aggregate, top-k and dimension join queries. Five alternating custom-one-worker, custom-four-worker and tuned DataFusion samples retain wall time, GNU-time peak RSS and exact ordered CSV digests. `--smoke --sizes 1000 --repeats 1` is correctness setup only. `--profile` is a separate syscall profile, excluded from reported measurements. No spill or disk-cache-cold claim.
- The separate `.github/workflows/profile.yml` builds optimized code with line information and runs `python3 scripts/profile.py --output evidence/callgrind`. Callgrind profiles custom1/custom4/DataFusion4 on the frozen 100k-row dimension join. Fixture and output digests must equal the original measured campaign. Per-side commands, raw instruction profiles and source/inclusive annotations survive cleanup. Hosted run 39732211058 passed all three exact-output checks and retained annotations. This is diagnosis, with no wall-time comparison.
- `.github/workflows/compare.yml` runs the existing verifier and builds baseline `1f73fca` plus the hashing candidate on one runner with Rust 1.99.1. `scripts/compare.py` retains all original 3 sizes/5 queries/3 executor arms on both builds, one warmup and five reversed rounds; Hyperfine 2.0.0 owns timing and schema-2 exports, GNU time owns resources, and frozen CSV digests gate every invocation. No new engine mode or inferred speedup. Draft until hosted verification passes.
